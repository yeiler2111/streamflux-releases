Cómo instalar

📱 Celular o tablet

  1. Toca Descargar APK.
  2. Abre el archivo descargado.
  3. Si Android lo pide, permite instalar apps desconocidas para tu navegador.
  4. Toca Instalar.

📺 Android TV / TV Box

  1. Instala la app Downloader desde la tienda de tu TV.
  2. En Downloader escribe:
    yeiler2111.github.io/streamflux-releases
  3. Pulsa Descargar APK con el control remoto.
  4. Permite instalar apps desconocidas para Downloader y confirma.

Las nuevas versiones llegan dentro de la app: verás un aviso “Actualización disponible”. No necesitas volver a esta página.
